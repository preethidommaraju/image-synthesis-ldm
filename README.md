# High-Resolution Image Synthesis with Latent Diffusion Models

> AI / Deep Learning Research Project | Associated with St. Francis College

## Overview

Built and trained **Latent Diffusion Models (LDMs)** for high-resolution image generation using **PyTorch** and cloud computing technologies. Designed end-to-end machine learning pipelines covering data preprocessing, model training, evaluation, and scalable inference workflows for AI-based image synthesis applications.

## Key Features

- 🤖 **Latent Diffusion Models** — Implemented state-of-the-art LDM architecture for high-res image synthesis
- 🔄 **End-to-End ML Pipeline** — Full pipeline from data preprocessing to scalable inference
- ☁️ **Cloud Computing** — Leveraged cloud infrastructure for model training and deployment
- 📊 **Model Evaluation** — Comprehensive evaluation metrics for image quality assessment
- ⚡ **Scalable Inference** — Optimized inference workflows for production deployment

## Pipeline Architecture

```
Dataset
   │
   ▼
Data Preprocessing
   │ (normalization, augmentation)
   ▼
Encoder (VAE)
   │ (image → latent space)
   ▼
Diffusion Process
   │ (forward: add noise)
   │ (reverse: denoise)
   ▼
Decoder (VAE)
   │ (latent space → image)
   ▼
High-Resolution Output
   │
   ▼
Evaluation (FID, SSIM, PSNR)
```
